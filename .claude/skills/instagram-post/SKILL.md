# Instagram post (assisted)

Assets and copy: `social/instagram/PROFILE-AND-CAPTIONS.txt`; images `post-01-introduction.png`, `post-02-blind-reveal.png`, `post-03-next-round.png` (never `preview.png`). Planned dates: Nov 22, 24, 26 2026 (America/Phoenix), a plan, not a schedule.

## Rules
- One post per owner approval. Before clicking Share, show: image file, full caption, alt text, account handle. Wait for a clear yes. An earlier yes does not cover the next post.
- The owner must already be signed in; never enter credentials. Stop at login, challenge or CAPTCHA pages and hand over.
- Use caption and alt text verbatim from the kit. "Profile link" wording only if the profile has the website set.
- Real content (blind reveals, quotes): only from approved published records, with exact quotes, dates and source labels; never invent replies; never present demo/scripted data as real (CLAUDE.md rule 4).
- No bulk posting, no commenting/DMing/following, no engagement automation, no payments. Do not retry a failed Share blindly: check the profile first to avoid a duplicate.

## Steps
1. Pick the post (default: next unposted by date). Check the profile grid to confirm it is not already live.
2. Instagram web: Create > Post, upload the PNG (use `file_upload`), keep the full 4:5 portrait, Next x2.
3. Paste caption; Accessibility > Alt text; paste alt text.
4. Show the preview summary, get the owner's yes, Share.
5. Verify it appears on the profile; report the post URL.
